# NEEDLE+ 🪡

Симулятор «найди иголку в стоге сена» — по духу игры **Find The Needle** (Steam), но с расширенными механиками.
Сделано на **Godot 4.7** (как и оригинал), собирается в Android APK бесплатно на GitHub Actions.

## Как играть (телефон)
- Левый виртуальный стик — идти (до упора = бег), свайп по экрану — обзор.
- Кнопки: **КОПАТЬ** (держать), **ВЗЯТЬ (E)** — подобрать/купить/поставить, **ПРЫЖОК**, **ДЕТЕКТОР (Q)**, **МЕНЮ**.
- На ПК: WASD, Shift — бег, ЛКМ/Пробел — копать, E — взаимодействие, Tab — меню, Q — металлоискатель, G — выбросить.

## Цикл игры
1. Копай стог (≈3.7 млн соломинок) руками и инструментами — тратится выносливость.
2. Продавай сено у стойки **SELL HAY** (или авто-стойкой).
3. Покупай инструменты (лопата, вилы, грабли, ведро, пылесос, металлоискатель).
4. Качай апгрейды (15 категорий × 16 уровней = 240), открывай техдерево (8 технологий).
5. Строй фабрику: конвейеры, харвестер, авто-продажа, дроны, сканер иголок.
6. Найди **6 иголок** в стоге. Металлоискатель пищит и показывает сигнал; сканер подсвечивает столбом света.

## Сборка
```bash
# локально: нужны Godot 4.7.2, Android SDK, JDK 17+
godot --headless --path . --export-debug "Android"
```
Или просто запушить в GitHub: workflow `.github/workflows/build-apk.yml` соберёт APK, прогонит автотесты и выложит его в **Releases**.

## Автотесты
```bash
godot --headless --path . -- --test
```
17 проверок: копание, перенос, продажа, апгрейды, технологии, машины, авто-продажа, иголки, сохранение.
